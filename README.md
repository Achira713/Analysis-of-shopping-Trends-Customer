# Exercise and Calories Analysis
# คำอธิบายข้อมูล (Data Description)

โฟลเดอร์นี้อธิบายข้อมูลที่ใช้ในโครงงาน **Exercise & Calories Analysis**

## 1. แหล่งที่มาและสิทธิ์การใช้ข้อมูล

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อชุดข้อมูล | Calories Burned Exercise Dataset |
| ประเภทข้อมูล | ข้อมูลกิจกรรมการออกกำลังกายและพลังงานที่เผาผลาญ (Exercise & Physical Activity Data) 1 แถวต่อผู้ใช้งาน/การออกกำลังกาย 1 รายการ |

## 2. ไฟล์ในโฟลเดอร์นี้

| ตำแหน่งไฟล์ | คำอธิบาย |
| --- | --- |
| `data/raw/exercise..csv` | ไฟล์ข้อมูลการออกกำลังกายและแคลอรี ไม่มีข้อมูลสูญหาย มี 15,000 แถว 9 คอลัมน์ |

## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ `exercise..csv`

ข้อมูลไม่มีข้อมูลสูญหายมีทั้งหมด 15,000 แถว ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย และจำนวนค่าว่างของแต่ละคอลัมน์

| คอลัมน์ | ชื่อคอลัมน์เดิม | ชนิดข้อมูล | คำอธิบาย / ค่าที่เป็นไปได้ | ค่าว่าง |
| --- | --- | --- | --- | ---: |
| `user_id` | User_ID | ตัวเลข | รหัสประจำตัวของผู้ใช้ (มีทั้งหมด 15,000 คน) | 0 |
| `gender` | Gender | ข้อความ | เพศของผู้ใช้ ได้แก่ male และ female | 0 |
| `age` | Age | ตัวเลข | อายุของผู้ใช้ หน่วยเป็นปี (ช่วง 20 ถึง 79 ปี) | 0 |
| `height` | Height | ตัวเลข | ความสูงของผู้ใช้ หน่วยเป็นเซนติเมตร (cm) | 0 |
| `weight` | Weight | ตัวเลข | น้ำหนักของผู้ใช้ หน่วยเป็นกิโลกรัม (kg) | 0 |
| `duration` | Duration | ตัวเลข | ระยะเวลาในการออกกำลังกาย หน่วยเป็นนาที (1 ถึง 30 นาที) | 0 |
| `heart_rate` | Heart_Rate | ตัวเลข | อัตราการเต้นของหัวใจขณะออกกำลังกาย หน่วยเป็นครั้งต่อนาที (bpm) | 0 |
| `body_temp` | Body_Temp | ตัวเลข | อุณหภูมิร่างกายขณะออกกำลังกาย หน่วยเป็นองศาเซลเซียส (°C) | 0 |
| `calories` | Calories | ตัวเลข | ปริมาณพลังงานที่เผาผลาญได้ หน่วยเป็นกิโลแคลอรี (kcal) | 0 |

**หมายเหตุ**
- จำนวนค่าว่าง (Missing Values) นับจากข้อมูลจำนวน 15,000 แถว พบว่าไม่มีค่าว่างอยู่ในชุดข้อมูลเลย (Missing Values = 0)
